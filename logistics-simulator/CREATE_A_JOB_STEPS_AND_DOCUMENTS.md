## v41 — Field format rules now enforced on the Job itself

Every rule below is the intersection of the formats the downstream documents already required, so a value that passes the Job form is accepted by every document it autofills into. A failing field turns red and the toast names the exact rule.

| Field | Rule (v41) |
|---|---|
| Vehicle Number | `KL07AB1234` — spaces / hyphens removed automatically, upper-cased |
| Seal Number | 6–15 letters/digits (hyphen allowed), upper-cased |
| Voyage / Flight No. | Sea: 2–10 letters/digits. **Air: airline code + 1–4 digits** (e.g. `AI508`, `6E512`) |
| Phone (Exporter / Importer) | 8–17 digits with optional `+`, spaces, hyphens |
| Importer GSTIN | GSTIN format when filled (leave blank for a foreign buyer) |
| PO Number | 4–10 digits, or `PO-YYYY-NNNN` |
| Quantity (packages) / Gross Weight / Invoice Value | greater than 0; packages = whole number; others up to 2 decimals |
| E-Way Bill / Delivery Challan / LR No. | 12 digits / 6–25 chars / 6–25 chars |
| Item: HS Code | exactly 8 digits |
| Item: Product Code | 4–15 letters/digits (hyphen allowed) |
| Item: Quantity, Unit Price, Weight, Net Weight | greater than 0 (up to 2 decimals); Discount ≥ 0 |
| Item: UN Number | `UN` + 4 digits (e.g. `UN1090`) |
| Item: Packing Group | I, II or III (dropdown) |
| Item: Manufacturing / Expiry Date | `YYYY-MM-DD` |

Cross-field checks (on Save, sea/air lots): **Invoice Value = Σ (Quantity × Unit Price − Discount)**; **Gross Weight = Σ item Weight (KG)** (TCOS hard-validates this); each item's **Net Weight ≤ Weight**.

Documents now fed by fields that previously went nowhere: Item **Product** → every "Product Name" field (Certificate of Analysis, E-Way Bill, MSDS, Halal/Kosher); Item **Tank Type** and **EmS Code** → two new columns on the Dangerous Goods Declaration.

HOW TO READ THIS FILE
  • One block per simulator document, in the order you should work (every document's prerequisites are already done before it).
  • Inside each document the STEP numbers and field names are the same as on the simulator screen; type exactly the value shown.
  • ⟵ auto-filled from Job Master / DOC xx  = the simulator fills it for you (do not retype; just check it).
  • ↳ same as DOC xx › Step n › field          = the same value was already written there; copy it from there (not repeated here).
  • ☑ TICK = tick these boxes.   ☐ LEAVE UNTICKED = do not tick.   "(leave blank – not applicable)" = leave the field empty.
  • DOC 01 – DOC 10 are written in full; from DOC 11 onwards repeated values point back to where they first appear.
  • All amounts are in INR. Dates are dd/mm/yyyy. All bank, customs, licence, carrier and TCOS numbers are simulated training references.

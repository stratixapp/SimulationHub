# assets/

Drop your own hero banner photo here as:

    assets/hero-banner.jpg

It's used as the background image behind the "File Your VAT Return Early"
banner on the homepage (index.html). If the file isn't present, the banner
still looks fine — it falls back to the navy/gold gradient background with
no broken-image icon.

No real UAE government seal, crest, or Federal Tax Authority artwork is
used anywhere in this simulator — the header uses plain text badges
("FTA" / "UAE") instead.
